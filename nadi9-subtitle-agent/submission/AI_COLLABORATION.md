# AI Collaboration Log

This file should be updated by the candidate with the tools actually used during development.

## Example format

### Task
Generate a first-pass Spring Boot controller.

### AI assistance
Used an AI coding assistant to draft controller boilerplate.

### Verification
- Reviewed validation annotations.
- Ran unit tests.
- Manually tested `/api/v1/health`.
- Checked that no assignment evidence was sent to an external service.

### Rejected suggestion
If the assistant suggested translating unsupported words instead of abstaining, the suggestion was rejected because the assignment requires evidence-grounded decisions.

## Rule

Do not claim that an AI tool performed work that it did not actually perform.
